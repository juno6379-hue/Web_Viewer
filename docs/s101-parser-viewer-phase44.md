# S-101 parser-viewer phase 44

## Summary

This phase connects the parser, database projection, API, and web viewer around the same S-101 feature/attribute/portrayal model.

- Dataset list and features are read from PostgreSQL projection views.
- Feature names and attribute names are resolved through the S-101 Feature Catalogue and DSID local code tables.
- Feature portrayal is generated by the S-101 Portrayal Catalogue Lua rules through LuaJIT.
- Symbol, line, fill, and text instructions are rendered from the Lua drawing instruction stream.
- Viewport loading can query merged features across datasets by bbox instead of requiring one selected dataset.

- `Sounding` now returns 3D source coordinates and Lua-generated sounding digit symbols, for example `SOUNDGC2,SOUNDG23,SOUNDG10,SOUNDG06`.
- `LightSectored` now preserves nested complex attributes and returns sector line instructions plus text, for example `Fl W 10s104m23M`.
- `LandArea`, `DepthArea`, `DepthContour`, `Coastline`, `Wreck`, `LightAllAround`, and other feature classes return Lua-derived line/fill/symbol instructions instead of a single default symbol path.
